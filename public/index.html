Chalisa Sangrah

App features

Built for daily paath — offline-first reading with thoughtful extras.

Offline reading

All 32 Chalisas are bundled locally. Read anytime without an internet connection. Adjust font size with A+ / A− for comfortable recitation.

Audio playback

Listen to Chalisas with background playback, a persistent mini player, and lock-screen controls. Audio streams when available — text always works offline.

Favourites & search

Save your go-to Chalisas with a tap. Search the full collection from the home screen and jump straight to what you need.

Hindi / English

Toggle between Hindi and English for the app interface. Chalisa text is available in both languages.

Light & dark theme

Switch between warm light and calm dark themes — matched to the same palette you see on this site.

Report an issue

Found a text error or missing verse? Report it directly from any Chalisa detail screen so we can review and improve the content.
